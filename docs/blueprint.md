# **App Name**: CareerCompass

## Core Features:

- Interest Profiler: User interest input form to capture interests, hobbies, and skills.
- Career Path Generator: AI-powered career path suggestion engine using a Tool to map interests to potential careers.
- Roadmap Visualizer: Roadmap visualization displaying the steps, skills, and resources needed for a selected career.
- Roadmap Download: Downloadable roadmap to save for offline access.

## Style Guidelines:

- Primary color: Teal (#008080) for a professional and trustworthy feel.
- Secondary color: Light gray (#F0F0F0) for clean backgrounds and content separation.
- Accent: Gold (#FFD700) to highlight key information and calls to action.
- Clean and readable sans-serif fonts for body text and headings.
- Use professional and consistent icons to represent different career fields and skills.
- Clean, responsive layout that adapts to different screen sizes.
- Subtle animations to guide users through the career roadmap.

## Original User Request:
career guidance chat bot application website which gives you a roadmap of the career you wish to pursue based on your interests and hobbies
